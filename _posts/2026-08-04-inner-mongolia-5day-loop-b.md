# 🗺️ 内蒙草原 5 天经典环线 B 方案（夜行承德版）

> **路线**：D0 晚北京（顺义）→ 承德（夜行）→ D1 承德 → 塞罕坝 → 乌兰布统 → D2-D5 与 A 方案一致（达达线+热阿线 → 克什克腾 → 沽源天路 → 北京）
> **车型**：两驱 SUV ｜ **里程**：约 1800km（环线）｜ **季节**：7-8 月
> **核心差异**：D0 晚 20:00 出发先赶 2.3h 夜路，D1 从容游塞罕坝+乌兰布统+公主湖

**总里程**：约 188km ｜ **用时**：2.3h（纯夜路，轻松）

## 📅 D3｜达达线 + 热阿线环线（草原公路精华）

**总里程**：约 280km ｜ **用时**：约 8h（含游玩+午餐+温泉）

| 时间 | 节点 | 里程 | 备注 |
|---|---|---|---|
| 7:00 | 早餐+退房 | 0km | |
| 8:00 | 乌兰布统出发 | 0km | 走 G303 |
| 9:30 | **贡格尔收费站** | 80km | 出口下来，正式上达达线 |
| 10:00 | **踏上达达线** | 100km | 彩虹公路，"中国北疆风景大道" |
| 12:00 | **巴彦查干苏木午餐** | 150km | ⚠️ **后面无正经餐馆** |
| 13:00 | **阿斯哈图石林南门** | 180km | **石林驿站**免费远眺 |
| 15:00 | **黄岗梁森林旅游区** | 220km | 山顶观景台（**导航设"森林旅游区"**） |
| 16:30 | **黄岗梁·盘山公路**（半山腰） | 225km | 绿+雾+云海组合 |
| 17:30 | **热水塘镇** | 260km | 温泉解乏（可选） |
| 18:30 | **经棚镇**入住 | 280km | 今日终点 |

### 🎯 今日重点

- **达达线**（中国最美草原公路，**全程柏油**）
- **阿斯哈图石林南门石林驿站**（免费远眺，省 160 门票）
- **黄岗梁山顶观景台**（连绵草甸+盘山路）

### ⚠️ 关键提醒

1. **石林驿站**：阿斯哈图南门往里开 5 分钟，路边停车区+观景台，**免费**看整片石林
2. **黄岗梁导航**：高德搜"**黄岗梁森林旅游区**"（不是"国家森林公园"）
3. **巴彦查干苏木**：达达线上**最后一个正经餐馆**
4. **区间测速**：达达线+热阿线全程 40-60km/h，**别超速**

### 🏨 住宿（经棚镇）

| 酒店 | 价格 | 备注 |
|---|---|---|
| **星程酒店** | 350-450/晚 | 连锁稳定，旺季提前订 |
| **克什克腾旗宾馆** | 250-350/晚 | 老牌政府接待 |
| **如家/汉庭** | 300-400/晚 | 连锁保险 |

### 🎯 今日重点

- **克什克腾石阵**（D3 远眺对比，**这次深度进**）
- **桦木沟国家森林公园**（**人少 90% 的隐藏点**）

### ⚠️ 关键提醒

3. **玉龙沙湖**：两驱车可到但要走一段沙土路，**雨后放弃**

## 📅 D5｜达里湖 → 太仆寺旗 → 沽源草原天路东线 → 北京

**总里程**：约 820km ｜ **用时**：约 11-12h（含午餐+天路拍照，**建议 7:00 前出发**）

| 时间 | 节点 | 里程 | 备注 |
|---|---|---|---|
| 7:00 | 早餐+退房 | 0km | |
| 7:30 | 经棚镇出发 | 0km | 走 G303 转 X218 |
| 9:00 | **达里湖北岸景区** | 60km | 草原马尔代夫，茅草屋+帆船 |
| 10:30 | **达里湖南岸**（可选） | 80km | 火山地貌+盐碱滩，**航拍最佳** |
| 11:00 | G303 向西走 | 80km | **不折返经棚镇** |
| 13:00 | **锡林郭勒**午餐 | 200km | 锡张高速入口 |
| 15:00 | **太仆寺旗** | 460km | **分叉点：右转沽源方向**（不去张北） |
| 16:00 | **沽源县** | 505km | 可顺路看滦河神韵/五花草甸 |
| 16:30 | **草原天路东线** | 505km | 沽源→桦皮岭 95km，风车群+林海 |
| 19:30 | **桦皮岭** | 600km | 天路东入口，**拍日落** |
| 20:00 | 上高速（京礼高速） | 600km | 崇礼方向 |
| 22:30 | **抵京（顺义枫泉）** | 820km | |

### 🎯 今日重点

- **达里湖北岸**（茅草屋+帆船）
- **草原天路东线**（沽源→桦皮岭 95km，风车群+林海，**今日重头戏**）
- **桦皮岭日落**（天路东入口，海拔高视野开阔）

### ⚠️ 关键提醒

1. **不走回头路**：G303 出达里湖后**直接向西**，**不折返**经棚镇
2. **分叉点在太仆寺旗**：原线走锡张高速去张北，本方案**右转沽源方向**（X501/S242），比原线只多约 12km
3. **草原天路东线是山路**：弯多坡陡限速低，95km 实际要开 2.5-3h，**拍照点多留足时间**
4. **到京时间较晚（约 22:30）**：如不想开夜车，可在沽源/崇礼住一晚拆成 D6

## 📋 行前必带清单

### 证件

身份证、驾驶证、行驶证、车辆保险单（**复印件**）

### 车用

- 行车记录仪（草原天路/达达线风景必录）
- 车载充电器 + 数据线
- 玻璃水（草原飞虫多）、备胎检查

### 衣物（7-8 月）

- 白天短袖 + **防晒衣/冰袖**（紫外线强）
- **早晚长袖/薄外套**（草原昼夜温差大，最低 10℃ 左右）
- 帽子、墨镜、防晒霜（SPF50+）

### 其他

- 现金少量（部分牧户家只收现金）
- 零食+水（达达线/草原天路补给点少）
- 驱蚊液（金莲花湿地/东沟草地）
